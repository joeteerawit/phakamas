# Design System Master File

> **LOGIC:** When building a specific Step, first check `design-system/thai-spelling/pages/[step].md`.
> If that file exists, its rules **override** this Master file. Otherwise follow the rules below.
> Base generated by ui-ux-pro-max (`kids educational learning game playful`, Motion 3, Density 3), then adapted to the grilled decisions: garden palette, Thai fonts, Motion (not GSAP), mascot.

**Project:** Thai Spelling · **Category:** Children's educational app (Grade 2) · **Mode:** light only

---

## Style

**Claymorphism on a garden backdrop.** Soft 3D, chunky, toy-like: thick borders (3–4px), rounded 16–24px, double shadow (outer drop + inner highlight), soft press. Step headings sit on a **wooden sign**. Page background is a full-bleed sky → grass gradient.

## Typography

| Use | Font | Size (mobile → desktop) |
|-----|------|------|
| Step heading, vocabulary words, big feedback | **Mali** 600/700 (`@fontsource/mali`, Thai subset) | heading 28→44px, vocabulary 32→44px |
| Body, buttons, labels | **Anuphan** 400/600 (`@fontsource/anuphan`) | body 18→24px, buttons 20px |

Line-height 1.6 for Thai (stacked tone marks need room). Self-hosted only; no Google Fonts requests. A teacher should confirm Mali letterforms are clear for beginning readers.

## Icons and Images

- **UI controls**: Lucide (`lucide-react`) SVG only: home, volume-2, volume-x, chevron-left/right, mic, square (stop), play, rotate-ccw, check, x, star. Every icon button has a Thai `aria-label`.
- **Content illustrations**: Microsoft Fluent Emoji 3D PNGs (MIT). Never used as control icons.
- **Mascot**: one monkey ("น้องลิง") appears across the Lesson: greets on Step 1, explains on Step 4, says "ถึงตาหนูอ่านแล้ว" and "เก่งมาก!" in feedback.

## Components

- **Button**: min height 56px (48px absolute minimum), pill radius, 3px border, `--shadow-clay`; press = translateY(4px) + `--shadow-clay-pressed` in 150ms; visible 3px focus ring; `cursor: pointer`.
- **Card** (vocabulary, choice, sentence): white, radius 24px, 3px border, `--shadow-clay`, image + word + speaker; selected = pink border; playing = blue glow.
- **Wooden sign**: Step heading on `--color-wood` plank with Mali white text.
- **Step navigation bar**: Back / Next pills.
- **Feedback toast**: mascot + message + ✓/✗ icon, announced via `aria-live="polite"`.

## Responsive Layout (mobile-first)

| Width | Layout |
|-------|--------|
| < 768px | Compact header (home, ขั้น X/10, mute); progress bar; single-column content; vocabulary grid 2 columns; **Back/Next bar fixed to the bottom** (thumb zone, respects safe-area inset); content padded so nothing hides behind it |
| 768–1023px | Vocabulary grid 3 columns; Back/Next bar still at bottom |
| ≥ 1024px | Content inside a centred **storybook** panel, max-width ~1100px, on the full-bleed garden; Back/Next at the bottom of the storybook |

Verify at 375, 768, 1024, 1440px. No horizontal scroll; zoom never disabled.

## Motion (Motion library, subtle)

- Max **2 animated elements per view**.
- Button press 150ms; feedback bounce on correct answer (~300ms spring); star burst when an Activity completes; Step change slides content horizontally (~250ms, exit faster than enter).
- `useReducedMotion()` → no slide/bounce, render final state immediately.
- Animate transform/opacity only, never width/height.

## Anti-Patterns (Do NOT Use)

- ❌ Dark mode
- ❌ Emojis as UI icons
- ❌ Colour-only right/wrong
- ❌ Hover-only affordances (children use touch)
- ❌ Text below 16px; gray-on-gray
- ❌ Instant state changes (always 150–300ms)
- ❌ Invisible focus states
- ❌ Content hidden behind the fixed bottom bar
